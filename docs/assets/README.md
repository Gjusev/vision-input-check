## Set the repository social preview

Committing the image does not set GitHub's social preview automatically.

1. Open [repository settings](https://github.com/Gjusev/vision-input-check/settings).
2. Under **Social preview**, choose **Edit → Upload an image**.
3. Select `docs/assets/social-preview.jpg`.

The image follows [GitHub's size and format guidance](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/customizing-your-repositorys-social-media-preview).
For a fork, use your own repository settings.

## Provenance

Created with the built-in image generation tool. [PROMPTS.md](PROMPTS.md) records
the prompts. ImageMagick was used only to resize and encode the delivery files:
512 × 512 PNG for the logo, 1280 × 640 JPEG at quality 90 for the preview.
No image-generation or rendering dependency is added to the Python package.
